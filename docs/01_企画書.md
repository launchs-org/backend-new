# Launchs-org 企画書

## 概要

Launchs-org は Kubernetes をバックエンドに持つ PaaS（Platform as a Service）です。
GitHub リポジトリからのワンクリックデプロイ・テンプレートによるミドルウェア起動・コンテナの管理を、シンプルな API と UI で提供します。

---

## 主な機能

| 機能 | 説明 |
|------|------|
| GitHub デプロイ | リポジトリURL・ブランチ・コミットハッシュ・サブディレクトリを指定してデプロイ |
| Webhook 自動デプロイ | コンテナに Webhook を設定し最新コミットを自動デプロイ |
| テンプレートデプロイ | MySQL・Redis などを YAML テンプレートから即時起動 |
| 内部サービス公開 | Kubernetes Service によるプロジェクト内ポート公開 |
| HTTP 公開 | {container-name}-{project-uuid}.launchs.org のサブドメインで自動公開 |
| ログ取得 | タイムスタンプカーソルベース・ビルドジョブ単位・Pod 単位で取得 |
| メトリクス取得 | CPU・メモリを from/to 範囲指定で取得 |
| ビルドジョブ管理 | ジョブごとのログ閲覧・停止 |
| ボリューム永続化 | プロジェクト単位で PVC を作成しコンテナにマウント |
| スケーリング | レプリカ数の手動変更（0でコンテナ停止）・Pod 単位でステータス確認 |
| フロー可視化 | プロジェクト内コンテナ間接続を React Flow で可視化 |
| スナップショット | デプロイごとに状態を保存し完全復元可能 |

## システムアーキテクチャ

### コンポーネント構成

```
クライアント (Vite + React + TypeScript, /ui/ 配下)
        |
        | REST API (/api/v1/...)
        v
    Backend (Echo + GORM)
        |               |
  Temporal発行      DB読み書き
        |               |
   Temporal         PostgreSQL
  /   |   \
ctrl watch build
  |    |    |
  +----+----+
        |
  Kubernetes API
  (Namespace / Deployment / Service / IngressRoute / PVC / BuildJob)
```

### 各コンポーネントの役割

#### Backend
- 全リクエストの受付（Echo フレームワーク）
- JWT Middleware で userId を取得し後続処理に渡す
- GORM + PostgreSQL でデータの永続化
- Temporal へのワークフロー発行
- Harbor 操作は行わない（Controller が担当）
- レスポンス形式: { "data": {...}, "error": null }

#### Controller
- Temporal の controller-queue を監視
- Kubernetes API を介してリソースを作成・更新・削除
- Harbor API を介してプロジェクト・Robot アカウントを管理
- launchs-managed=true ラベルを全リソースに付与

#### Watcher
- Temporal の watcher-queue を監視
- launchs-managed=true ラベルの全リソースを監視
- Deployment 単位・Pod 単位でステータスを収集
- ログは 3 秒バッファリングして PostgreSQL に一括 INSERT
- メトリクスは Metrics Server から 15 秒ごとに収集・30 日保持

#### Builder
- Temporal の builder-queue を監視
- 既存の railpack ライブラリ（BuildKit rootless）を使用
- buildkit Namespace でビルドジョブを実行
- ビルド完了後 Harbor レジストリにイメージをプッシュ

## データモデル

### 階層構造

```
User
└── Project (Namespace: project-{uuid})
    ├── Container (Deployment)
    │   ├── Port
    │   ├── NetworkRoute (Service / IngressRoute)
    │   ├── ContainerEnvVar
    │   ├── PodStatus (Pod 単位のリアルタイムステータス)
    │   ├── ContainerLog (Pod 単位)
    │   ├── ContainerMetric (Pod 単位)
    │   ├── ContainerStatusHistory (最新 100 件)
    │   ├── Deployment (デプロイ履歴)
    │   └── BuildJob
    │       └── Image
    ├── Volume (PVC)
    ├── ProjectEnvVar (共通環境変数)
    ├── ServiceConnection (フロー可視化用)
    └── Snapshot
```

### コンテナステータス

| ステータス | 説明 |
|-----------|------|
| pending   | 作成直後・初回ビルド前 |
| building  | ビルド中 |
| deploying | Kubernetes へのデプロイ中 |
| running   | 正常稼働中 |
| scaling   | スケーリング中 |
| failed    | 異常終了 |
| stopped   | 停止中（レプリカ数 0） |

### Pod ステータス（Watcher が管理）

| フィールド | 説明 |
|-----------|------|
| pod_name | Kubernetes Pod 名 |
| status | Running / Pending / Failed / Succeeded / Unknown |
| ready | Ready 状態かどうか |
| restart_count | 再起動回数 |
| node_name | 稼働ノード名 |
| started_at | 起動日時 |

### リソースサイズ

| サイズ | CPU Request | CPU Limit | Memory Request | Memory Limit |
|--------|-------------|-----------|----------------|--------------|
| Small  | 100m        | 500m      | 128Mi          | 256Mi        |
| Medium | 500m        | 1000m     | 512Mi          | 1Gi          |
| Large  | 1000m       | 2000m     | 1Gi            | 2Gi          |

## ワークフロー一覧

| ワークフロー名 | キュー | 内容 |
|--------------|--------|------|
| CreateProjectWorkflow | controller | Namespace・Harbor プロジェクト・Robot アカウント作成 |
| DeleteProjectWorkflow | controller | Namespace・Harbor プロジェクト・PVC 削除 |
| CreateVolumeWorkflow | controller | PVC 作成 |
| DeleteVolumeWorkflow | controller | PVC 削除 |
| BuildDeployWorkflow | builder + controller | ビルド・Deployment・Service・IngressRoute 作成 |
| DeployWorkflow | controller | 既存イメージから Deployment・Service・IngressRoute 作成 |
| RedeployWorkflow | controller | 変更を適用して Deployment 更新 |
| DeployProjectWorkflow | controller | 全コンテナ一括再デプロイ・スナップショット作成 |
| ScaleWorkflow | controller | レプリカ数変更（0 で停止） |
| DeleteContainerWorkflow | controller | Deployment・Service・IngressRoute 削除 |
| CreateServiceWorkflow | controller | Kubernetes Service 作成 |
| DeleteServiceWorkflow | controller | Kubernetes Service 削除 |
| CreateIngressWorkflow | controller | IngressRoute 作成 |
| DeleteIngressWorkflow | controller | IngressRoute 削除 |
| MountVolumeWorkflow | controller | Deployment にボリュームをマウント |
| UnmountVolumeWorkflow | controller | Deployment からボリュームをアンマウント |
| RestoreSnapshotWorkflow | controller | スナップショットから全コンテナを復元 |

### Dockerfile パターン（各コンポーネント共通）

```dockerfile

WORKDIR /app
COPY go.mod go.sum ./
RUN go mod download
COPY shared/ ./shared/
COPY backend/ ./backend/
RUN go build -o /bin/app ./backend/src

FROM alpine:3.19
RUN apk add --no-cache ca-certificates tzdata
COPY --from=builder /bin/app /bin/app
ENTRYPOINT ["/bin/app"]
```

## フロントエンド構成

### 技術スタック

| 項目 | 技術 |
|------|------|
| フレームワーク | Vite + React + TypeScript |
| UI コンポーネント | shadcn/ui |
| ルーティング | React Browser Router |
| 状態管理 | useState / useContext |
| API 通信 | fetch ラッパー関数 |
| グラフ | Recharts |
| フロー可視化 | React Flow (@xyflow/react) |
| 公開パス | /ui/ 配下 |

### ページ構成

| パス | 内容 |
|------|------|
| /ui/ | ランディング |
| /ui/projects | プロジェクト一覧（名前・コンテナ数・最終デプロイ日時） |
| /ui/projects/:id | プロジェクト詳細（React Flow フロー可視化がデフォルト） |
| /ui/projects/:id/containers/:id | コンテナ詳細 |
| /ui/projects/:id/volumes | ボリューム管理 |
| /ui/projects/:id/settings | プロジェクト設定・環境変数 |
| /ui/projects/:id/snapshots | スナップショット一覧・復元 |

### コンテナ詳細タブ

| タブ | 内容 |
|------|------|
| 概要 | ステータス・Pod 一覧（Pod ごとの状態）・リソース使用量 |
| ログ | ランタイムログ/ビルドジョブログ切替・Pod 選択・検索・自動スクロール |
| メトリクス | CPU・メモリ折れ線グラフ（from/to 指定） |
| サービス | Kubernetes Service・IngressRoute 管理 |
| 設定 | 環境変数・ポート・ボリュームマウント |
| デプロイ履歴 | デプロイ一覧・ビルドジョブ一覧 |
